# AFL Player Guesser V5

- Home page has 18 colour-coded AFL club buttons.
- Each club uses the supplied 2026 player/club list as the answer set.
- Autocomplete searches all players, not only the selected club.
- Overall rarity totals appear on the home page.
- Five achievements are initially greyed out and only show their requirement after unlocking.
- Achievement unlocks persist in browser localStorage.
- Career-game data is populated where available; missing values are explicitly marked as pending.
