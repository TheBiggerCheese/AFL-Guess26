# AFL Team Guess

A mobile-friendly AFL team guessing game designed for GitHub Pages.

## Current version

Version 1 contains the Melbourne 2026 player list and the guessing interface.

The game is deliberately built with:
- `index.html` — page structure
- `style.css` — mobile-friendly design
- `game.js` — game logic and player data

## GitHub Pages

GitHub Pages can publish a static HTML/CSS/JavaScript project directly from a GitHub repository.

Create a public repository, upload these three files, then go to:

**Settings → Pages → Build and deployment**

Choose **Deploy from a branch**, select `main`, and choose `/ (root)`.

Your game will then be available at:

`https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`
